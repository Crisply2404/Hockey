# 成品化

把只有比赛画布和表单式大厅的 Hockey 做成可以直接拿出来玩的成品。它要看上去是一个东西，不臃肿，不平庸：效果和界面只用球桌自己的材料（见 `docs/adr/0002-table-materials-only.md`）。

- 主菜单：标题和几个词；背后是演示比赛。
- 比赛：发球倒计时、暂停、一局结束后的进球线图、再来一局。比分只显示在球桌上。
- 画面：边墙是弦，屏障是皮筋，球路留线。没有粒子和彩条。
- 声音：全部用 Web Audio 合成，撞墙是五声音阶上的音。
- AI：推算球路、绕到球后、朝目标挥拍；三档难度。
- 判定：击球后不再穿过球拍；轻触对双方生效；连击爆发背离球拍；超速衰减按时间。
- 尺寸：球拍半径 26，冰球半径 15。
- 界面：词、线条图标、与球桌同线宽的直角方框。开关只有声音、黑白主题、语言。
- 触屏与竖屏：指针事件、本地双人各控半场、竖屏旋转球桌。
- 联机：进入大厅时才连接、邀请链接、访客插值与本机球拍预测；联机协议与 Worker 保持不变。
- 结构：比赛拆成模拟、AI、画面三个模块，画布组件只管主循环、输入与联机。
