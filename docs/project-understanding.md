# Hockey：元素、操作与项目说明

核查日期：2026-11-26。术语见 [GLOSSARY.md](../GLOSSARY.md)，设计决定见 [docs/adr/](./adr/)。本文记录当前源码中的规则、操作、数据流和验证范围。

## 页面与入口

| 页面 | 作用 | 入口与返回方式 |
| --- | --- | --- |
| 主菜单 | 标题和三个词：人机对战（下方选难度）、本地双人、联机对战；右上角是语言、黑白主题、声音 | 网页打开后默认显示 |
| 本地比赛 | 人机对战或者同一设备上的双人对战 | 主菜单；暂停或者一局结束后的方框里选「返回菜单」 |
| 大厅 | 输入玩家名称、创建房间、按编号或者从列表加入 | 主菜单的「联机对战」，或者打开邀请链接；左上角箭头返回 |
| 房间 | 等待对手与联机比赛 | 创建或者加入房间；左上角箭头确认后离开 |

刷新网页会回到主菜单；地址带有 `?room=编号` 时直接进入大厅并加入该房间。主菜单与大厅背后是演示比赛。界面文字有中文与英文两套，默认跟随浏览器语言。

## 球桌与物件

球桌的逻辑尺寸为 800 × 450，按可用区域的 90% 等比例缩放，四周留白用来画屏障绷出去的部分。画面高度大于宽度时球桌旋转 90°：访客的右半场、其余情况的左半场位于画面下方。

| 元素 | 尺寸与作用 |
| --- | --- |
| 边墙 | 六段，都是弦；线宽 3 |
| 球拍 | 半径 26。左方中心空心圆环，右方实心圆点 |
| 冰球 | 半径 15，内部十字随旋转转动 |
| 球门 | 开口高 160，以球桌高度中央为中心 |
| 球门屏障 | 开口处的皮筋 |
| 球门禁区 | 半径 85；球拍中心与球门中心至少相隔 111 |
| 比分 | 左右半场中的大数字，是唯一的比分显示 |
| 速度读数 | `v = …`，冰球速度平滑后乘以 3 取整 |

球拍与冰球原来的半径是 30 和 20。按球桌短边算，原来的球拍直径占 13%，真实气垫球桌约为 8%；缩小后球路和弧线有更多地方展开。尺寸集中在 [src/game/table.ts](../src/game/table.ts)。

## 操作

| 操作对象 | 输入 | 说明 |
| --- | --- | --- |
| 本方球拍 | 移动鼠标、触摸 | 球拍跟随指针位置，每帧最多移动 100 |
| 本方球拍 | `W`、`A`、`S`、`D`，人机对战和联机时方向键也可以 | 按画面方向移动；有按键时优先于指针 |
| 右方球拍（本地双人） | 方向键，或者触摸右半场 | 两根手指可以同时各控一方 |
| 暂停 | `Esc`、`P`、左上角图标 | 仅本地比赛；页面失去焦点或者切到后台时自动暂停 |

碰到冰球就是击球，没有击球键。难度在主菜单选择，与语言、主题、静音、玩家名称一起保存在浏览器的 `localStorage`（键 `hockey.settings.v1`）。

## 规则

1. 开局冰球停在中央，三拍发球倒计时（126 帧）后随机发向一方。此后每个得分回合前是一拍（48 帧），冰球发向刚丢分的一方。
2. 冰球速度有下限 6 和上限 50；超过上限时逐渐衰减，瞬时可以更高。旋转使球路弯曲，旋转强度限制在 ±0.7 并随时间衰减。
3. 屏障：冰球接触屏障时，水平速度达到 12 并且不在开口两端各 18 的范围内，屏障被打穿；否则弹回。
4. 屏障打穿后，冰球完整越过端线即进球，进入约 1 秒的慢动作（运动放慢到 0.1 倍），然后进攻方得一分，双方屏障恢复。
5. 先得 7 分的一方获胜。

球拍击球沿用原有调校：球拍速度按线性映射限幅后参与碰撞，迎着冰球挥拍追加力度，后撤可以卸力，切向相对速度变成旋转。相对原来有四处改动：

- 一次击球后的 20 帧内，同一只球拍再碰到冰球仍然做物理分离（原来完全不碰撞，冰球会穿过球拍），只是不重复触发停顿与旋转。
- 轻触规则对双方球拍都生效（原来只对左方）。
- 连击爆发的方向是背离球拍、左右各偏最多约 45°（原来是完全随机的方向）。
- 超速衰减按时间计算（原来按帧，高刷新率屏幕上衰减更快）。

来源：[src/game/sim.ts](../src/game/sim.ts)。

## AI 对手

每一帧：取若干帧之前的冰球状态（模拟反应延迟），往前推算球路并算上边墙反弹；找出最早能赶到的击球位置——冰球背对目标的一侧；赶得到就过去，够近时穿过冰球朝目标挥拍；直线过去会先撞到冰球时从侧面绕；赶不到就退到球门与冰球连线上、禁区外侧的位置防守。每轮进攻开始时选一个瞄准点，偏向对方球拍不在的一侧。

| 档位 | 移动速度 | 挥拍速度 | 延迟（帧） | 推算（帧） | 瞄准偏差 |
| --- | --- | --- | --- | --- | --- |
| 简单 | 7 | 11 | 12 | 26 | ±85 |
| 普通 | 11 | 17 | 7 | 40 | ±40 |
| 困难 | 16 | 25 | 3 | 55 | ±12 |

原来的 AI 直线冲向冰球，并在击球后直接改写冰球的旋转来让球弯进门；这两点都去掉了。这些数值没有经过对局调校。来源：[src/game/ai.ts](../src/game/ai.ts)。

## 画面与声音

| 发生的事 | 画面 | 声音 |
| --- | --- | --- |
| 撞边墙 | 那段墙像被拨的弦一样抖动 | 五声音阶上的一个音，由撞击位置决定 |
| 屏障弹回 | 皮筋大幅抖动 | 低沉的一声 |
| 屏障打穿 | 冰球顶着皮筋出界，顶出 40 后绷断，两截缩回门柱 | 绷断的一声 |
| 球拍击球 | 冰球压扁再恢复；击球停顿，画出蓝色速度箭头与红色旋转箭头；球拍中心扩出一圈波纹；画面震动 | 闷响，越快越亮 |
| 冰球运动 | 最近一拍的球路以淡线跟在后面 | — |
| 得分 | 进球球路留在桌面上；得分方的比分数字闪动 | 一声下行的低音 |
| 获胜 | 球拍与冰球淡出，球桌退成淡底，进球球路按顺序重画成线图，胜方的深、负方的浅 | 每条一个音，逐个升高 |
| 暂停 | 时间停住，冰球画出速度箭头与旋转箭头 | — |

去掉了碰撞火花、碰撞波纹、屏障碎片和胜利彩条。全部声音由 Web Audio 即时合成。来源：[src/game/view.ts](../src/game/view.ts)、[src/game/strings.ts](../src/game/strings.ts)、[src/audio/sfx.ts](../src/audio/sfx.ts)。

## 界面

界面只有三样东西：可以点的词、线条图标、用球桌线宽画出的直角方框。比赛画布把边墙在屏幕上的粗细写入 CSS 变量 `--line`，方框、输入框的底线、图标和下划线都用它。

| 方框 | 内容 |
| --- | --- |
| 暂停 | 继续、重新开始、返回菜单 |
| 一局结束（线图画完之后） | 再来一局、返回菜单；联机访客看到「等待房主开始下一局」和「离开」 |
| 等待对手 | 房间编号、「等待对手加入」、复制邀请链接 |
| 离开房间 | 一句说明、留下、离开 |
| 大厅 | 名称、房间编号与「加入」、可加入的房间列表、「创建房间」（未连接时显示「连接中…」） |

来源：[src/app/](../src/app/)、[src/styles.css](../src/styles.css)。

## 联机

| 环节 | 职责 |
| --- | --- |
| 大厅服务 | Cloudflare Worker 与 Durable Object：保存连接与房间、校验消息、转发输入和快照 |
| 房主 | 控制左方、接收访客输入、计算比赛、每 50 毫秒发送一份快照 |
| 访客 | 每 33 毫秒发送输入；显示经过插值的快照；本机先行移动自己的球拍 |

进入大厅或者房间时才连接服务。房间进入两人后，房主一侧以零比零开始新的比赛。访客不计算比赛：比赛事件由相邻快照的差异还原，撞墙的位置与力度来自快照里的碰撞记号，发球倒计时在看到冰球回到中央时由本机计时。联机协议与 Worker 没有改动，取舍见 [ADR 0001](./adr/0001-guest-derives-events-from-snapshots.md)。

房主的页面处于后台时，浏览器停止调用主循环，比赛随之停住。
