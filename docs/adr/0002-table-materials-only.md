# 效果与界面只用球桌自己的材料

球桌上原有的东西是：纸色、墨色、一种线宽、直线、正圆、时间停住时的蓝色速度箭头与红色旋转箭头。新加的效果和界面都从这几样里做，不引入别处的现成做法。

这条规矩来自两次返工。第一次做成品时，暂停、设置、结算用的是网页应用的圆角卡片、胶囊按钮和关闭叉，获胜时喷彩条，碰撞时掉火花；它们各自都“能用”，但放在一起，游戏看上去像两套东西拼的，也和任何一个网页小游戏没有区别。

按这条规矩得到的具体做法：

- **撞墙是拨弦。** 六段边墙和两根屏障都是两端固定的弦，被撞到的地方推出一个尖角再抖动衰减。不再有火花和波纹。声音是五声音阶上的一个音，音高由撞在哪根弦的哪个位置决定。
- **屏障是皮筋。** 慢球被兜住弹回；快球顶着它出界，在进球慢动作里绷断，两截缩回门柱。击破门槛从水平速度 6 提到 12，使“兜住”真的会发生。
- **一局的结尾是一张线图。** 每个进球的球路留在桌面上；分出胜负后，球拍与冰球淡出，球路按进球顺序重画，每画一条响一个音。不再有彩条、结算面板和统计数字。
- **暂停是时间停住。** 冰球上画出速度箭头与旋转箭头，和击球停顿的画法相同；选项写在一个方框里。
- **界面的线与球桌的线一样粗。** 比赛画布把球桌边墙在屏幕上的粗细写入 CSS 变量 `--line`，方框、输入框的底线、图标和下划线都用它。方框是直角的，里面直接写词，没有标题栏、关闭按钮和实心按钮。

## Consequences

- 设置面板、玩法说明、音量滑杆、画面震动开关和局分选择都去掉了。留下的开关只有声音、黑白主题和语言三个图标或词。局分固定为七分；画面震动只在系统没有要求“减少动态效果”时出现。
- 没有任何文字教程。屏障要用快球才能打穿，这一点靠皮筋把慢球兜回来的样子来说明。
- 以后加任何画面或界面，先问它能不能用上面那几样材料做出来；做不出来的，多半是不该加。
